File Excel

«Scarica Excel» genera un file con la stessa struttura del tuo Monitoraggio_Spese.xlsx (registro + riepilogo + patrimonio, con formule). «Carica Excel» sostituisce i dati dell'app con quelli del file.

Regole di categorizzazione Revolut

Le regole si applicano all'import dell'estratto conto: la prima che corrisponde vince. Le spese non riconosciute finiscono in «altro», le entrate in «cashback».

Backup

«Invia backup» è quello che ti salva se perdi il telefono: manda il file dove vuoi tu (Drive, email, WhatsApp…), così esce da questo dispositivo. «Salva sul telefono» lo mette solo nei Download: se il telefono si rompe, si perde anche il backup.
Per rimettere i dati su un telefono nuovo: apri l'app, poi «Ripristina backup».

Backup automatico su Google Drive

Una volta collegato, il backup si carica da solo sul tuo Drive quando apri l'app ed è passato un mese dall'ultimo. L'app usa il permesso più stretto possibile: vede solo i file che crea lei, non il resto del Drive. Finché non lo colleghi, l'app non contatta nessun server esterno.
